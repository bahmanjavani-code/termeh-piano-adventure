# 🎹 Termeh Piano Adventure — پیانوی ترمه

یک بازی آموزشی فارسی برای اندروید، ویژه تمرین نت‌خوانی کلید فا و سل، ارزش زمانی نت‌ها و فروشگاه سکه‌ای.

## امکانات نسخه آزمایشی 1.0
- نت‌خوانی تصادفی روی حامل در کلید فا و سل، با چهار پاسخ و پخش صدای نت
- تمرین جمع کشش نت‌ها (سیاه، چنگ، دولاچنگ، سفید و سیاه نقطه‌دار)
- تلاش برای تشخیص **یک نت در هر لحظه** از طریق میکروفون گوشی (آزمایشی)
- فروشگاه بدون پرداخت واقعی، ستاره و سکه؛ ذخیره پیشرفت روی گوشی
- تمام محتوای بازی داخل APK قرار دارد و برای اجرای اصلی به اینترنت نیاز ندارد

**محدودیت‌ها:** تشخیص نت میکروفون آزمایشی است و ممکن است به‌دلیل نویز، هارمونیک‌ها یا محدودیت WebView گوشی خطا کند. تشخیص آکورد و ارزیابی اجرای کامل ریتم هنوز پیاده‌سازی نشده است. مربی هوش مصنوعی آنلاین نیز هنوز در این نسخه وجود ندارد. رابط کاربری اولیه است.

## ساخت APK در GitHub (بدون کامپیوتر)
1. همه فایل‌های این پروژه را در ریشه مخزن GitHub آپلود کنید (ZIP را مستقیماً به عنوان یک فایل آپلود نکنید؛ ابتدا Extract کنید).
2. در تب **Actions** گردش کار **Build Android APK** را اجرا کنید یا منتظر اجرای خودکار بعد از Push بمانید.
3. پس از موفقیت، داخل همان اجرای Actions، بخش **Artifacts** فایل **Termeh-Piano-APK** را دانلود کنید.
4. ZIP خروجی Actions را باز کنید و `app-debug.apk` را روی گوشی نصب کنید. ممکن است Android درخواست اجازه نصب از این منبع را بدهد.

> APK با GitHub Actions ساخته می‌شود؛ فایل ZIP سورس‌کد است، نه APK آماده. نسخه debug برای نصب آزمایشی است.

## Privacy
ضبط میکروفون صرفاً در گوشی پردازش می‌شود و فایل صوتی به سروری ارسال نمی‌شود. برنامه به اینترنت یا کلید API نیاز ندارد.
