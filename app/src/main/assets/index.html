روش اول: تبدیل ۱ دقیقه‌ای به فایل APK اندروید (بدون برنامه‌نویسی)

  1. کد این صفحه را با نام index.html ذخیره کنید.
  2. نرم‌افزار رایگان Website 2 APK Builder (روی ویندوز) یا سایت webintoapp.com را باز کنید.
  3. گزینه Local HTML Website را انتخاب کرده و فایل index.html را به آن بدهید.
  4. دکمه Generate APK را بزنید تا فایل نصبی اندروید با آیکون دلخواه شما ساخته شود!
